## How we read the answers

81 saved checks of answer pairs in this audit. Checking models: openai/gpt-6-luna.

A checking model read each pair of answers, with and without search. It recorded the first-choice brand or no clear choice.

The checking model can miss answers that recommend several apps. A list without a clear ranking is not a single winner.

Reason labels describe two answers together. They do not explain a specific brand choice in one answer.

We read selected passages to explain the stated reasons. We did not count every reason in every answer.

0 label corrections in this view are saved separately. We keep the original labels, explanations and file checks.

We reviewed selected cases. We did not check every answer a second time.

We compare repeated answers to the same question, language, model and search setting. A missing answer means the group is incomplete.

A group is consistent only when every answer chooses the same app. Repeated unclear answers do not count as a winner.

We do not test statistical significance or estimate market share. We do not prove that search caused a choice.



## Search and sources

We record search use when the API returns search counts or citations. A model can still know web content without searching.

A returned link does not prove that a model read the page or based a claim on it. We did not check whether brand, safety or airport claims are true.

We group sources by domain. Source counts do not show independent support or source quality.



## Limits

Three questions in one city do not cover every customer need. Each answer was repeated three times.

Model claims about prices, licensing, partnerships and safety features may be wrong or out of date.

Recommendations do not measure safety incidents, service quality or what riders would choose.

Future checks need similar questions, translations, model versions and search settings to measure change.

NotebookLM may draw its own conclusions. Check them against the original answers.
